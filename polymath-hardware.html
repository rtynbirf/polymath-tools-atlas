polymath · power & cooling

Питание и охлаждение — критично

RTX 5090 потребляет 575W на пике. 4× = 2300W только GPU. Добавим CPU (350W TDP Threadripper), RAM, NVMe, вентиляторы — 2.4kW для Tower Pro, 3.8kW для Rack Beast. Это сопоставимо с масляным обогревателем. Решить вопрос охлаждения — иначе троттлинг убьёт производительность.

01

Tower Pro: 2.4 kW тепла

Custom water loop EKWB на 4 GPU + CPU. Два радиатора MO-R3 420mm выносят ~2.5kW при дельте 15°C. Насос D5 + резервуар 250ml. Вентиляторы Noctua A14 industrial — 6 шт. на 600 RPM. Шум 38 дБ. Без водянки — 4 blower-кулера под нагрузкой дают 65+ дБ, как пылесос.

02

2× PSU 1600W с Add2PSU

Один Corsair AX1600i тянет CPU+2 GPU, второй — ещё 2 GPU + периферию. Add2PSU синхронизирует включение. Цифровой мониторинг через iCUE. Альтернатива: 1× Seasonic PRIME TX-2000 (2000W), но нужен special-order.

03

Помещение: 15 m² минимум

Tower Pro выделяет 2.4kW тепла. Летом без кондиционера температура поднимется на 8-10°C за час. Нужен сплит 12000 BTU (3.5kW cold). Rack Beast — 24000 BTU. Счёт за электричество при 24/7 = $260/мес (Tower) или $410/мес (Rack).

04

Rack Beast: 3.8 kW, нужен шкаф

4U Supermicro chassis с 8 GPU blower — шум 65 дБ, как сервер в дата-центре. Штатные радиаторы GPU выдувают горячий воздух наружу. Альтернатива: иммерсионное охлаждение в баке с Engineered Fluids ElectroCool — добавляет $2000, но тишина и +30% производительности.

05

UPS обязателен

APC Smart-UPS SRT 3000VA для Tower Pro ($1500) — 30 минут автономии при 2.4kW. Для Rack Beast — APC Symmetra LX 8kVA ($5000), 20 минут. Задача UPS не «работать часами» — а корректно завершить vLLM, сохранить модели в cache.

06

Mac Studio: 270W, без вопросов

Mac Studio M3 Ultra потребляет 270W — меньше, чем одна RTX 5090. Пассивное охлаждение, 18 дБ. UPS APC Back-UPS Pro 1500VA ($250) даёт 40+ минут автономии. Идеально для квартиры — никаких спец-требований.

07

Электрика: 32A 220V линия

Для Tower Pro — отдельный автомат 16A на 220V. Для Rack Beast — 32A 220V (нужна спец-розетка CEE 7/7 и линия 4mm²). Стандартная квартирная проводка 2.5mm² на 16A не выдержит 3.8kW持续. Вызов электрика обязателен.

08

Кабели: 4× PCIe 12V-2x6

RTX 5090 использует новый разъём 12V-2x6 (600W). 4× GPU = 4× кабеля от PSU. Не использовать переходники 4× 8-pin → 12V-2x6 — они плавятся при пике. Только нативные кабели. Плохо вставленный 12V-2x6 = пожар.

нормы: IEC 62368-1 (безопасность) · NFPA 70 (электрика) · ASHRAE TC 9.9 (температурные режимы 18-27°C) · OSHA 1910.95 (шум ≤ 85 дБ)

polymath · software stack

Софт-стек — что крутится на железе

Железо без софта — кусок кремния. Polymat запускает стек, в котором каждый агент живёт в своём процессе, общается через Redis/NATS, хранит контекст в Qdrant, генерирует медиа через ComfyUI. Всё локальное, всё open-source, всё из каталога 665 инструментов.

СУД-агент (главный)

vLLM + Llama 3.3 70B Q4

Главный LLM, рассуждает, принимает решения, верифицирует. vLLM с PagedAttention, tensor-parallel на 2× GPU. 48GB VRAM, 50-70 ток/сек на Tower Pro.

МАШИНА (поиск/сбор)

3× vLLM + Llama 3.1 8B Q8

Параллельные агенты для рутины: web-парсинг, классификация, суммаризация. Continual batching обрабатывает 100+ параллельных запросов. 180-250 ток/сек каждый.

ИИ (рассуждение)

Ollama + DeepSeek-R1 32B

Reasoning-модель с visible chain-of-thought. Запускается через Ollama (проще API) или vLLM (быстрее). 20GB VRAM. Для задач где нужно «подумать вслух».

СЛОВАРЬ (граф)

Neo4j + Qdrant + Infinity

Граф связей между статьями (Neo4j), векторная база для RAG (Qdrant), embedding server (Infinity на Rust, 10K docs/sec). Хранит весь каталог 665 статей.

Генерация картинок

ComfyUI + FLUX.1-dev

Node-based UI для diffusion-моделей. FLUX.1-dev — лучшее качество. SDXL Turbo — для набросков. 16GB VRAM, 1 картинка/3 сек. Поддерживает LoRA, ControlNet, IPAdapter.

Генерация видео

ComfyUI + Wan 2.5 / CogVideoX

Wan 2.5 (Alibaba, open-source) — 5 секунд видео 720p за 4 минуты на 4× 5090. CogVideoX 5B — альтернатива. 40GB VRAM. Полностью локально, без подписки Runway/Sora.

Голос: STT

whisper.cpp + faster-whisper

Whisper-large-v3 на C++ (whisper.cpp) или Python (faster-whisper). Realtime в 12× быстрее реального времени. 4GB VRAM. Поддержка 99 языков, word-level timestamps.

Голос: TTS

F5-TTS / StyleTTS2 / Piper

F5-TTS — zero-shot клонирование голоса за 6 секунд, качество на уровне ElevenLabs. StyleTTS2 — стиль-перенос. Piper TTS — для edge. 4GB VRAM. Realtime в 4× быстрее.

Code-агенты

Aider + OpenHands + Cline

Aider — pair programming в терминале. OpenHands — автономный dev-агент. Cline — VS Code extension. Все три через локальный Ollama/vLLM endpoint. Никакого облака.

Оркестрация

n8n + LangGraph + Redis

n8n — visual workflow automation. LangGraph — агентный фреймворк. Redis — pub/sub между агентами. Вся логика Polymat: кто что делает, когда зовёт кого.

Веб-интерфейс

Open WebUI + Lobe Chat

Open WebUI — самохостящийся UI для Ollama, как ChatGPT. Lobe Chat — альтернатива с плагинами. Оба ходят к локальному vLLM endpoint. Доступ с любого устройства в LAN.

Мониторинг

Grafana + Langfuse + nvtop

Grafana — дашборд CPU/GPU/RAM. Langfuse — LLM observability (токены, латентность, cost). nvtop — realtime GPU utilization в терминале. Всё локально, без Datadog.
